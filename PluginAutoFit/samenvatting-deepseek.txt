# **Complete RDV Architectuur - Logische Synthese**

## **I. Hoofdstructuur & Algemene Principes**

### **1. Scheiding van Verantwoordelijkheden**
- **Boeren-Ring Filter (Producer)**: Produceert alleen ruis-gefilterde normals. Bevat **geen** stem- of cache-logica.
- **RDV-Kernel (Voter)**: Bevat alle intelligente logica: vlak-burst detectie, buis-FIFO beheer, as-verfijning (nudging).

### **2. Parallelle Architectuur Hiërarchie**
```
Host (Paginering) → Chunks (Map) → Regions (Shared Memory)
```
- **Micro-niveau (Region)**: 4k-16k punten, Shared Memory, voor GPU-efficiëntie
- **Macro-niveau (Pagina/Chunk)**: 22.5M-3.5 GB, Global Memory, voor VRAM-beheer
- **Consistentie**: De paginering vormt input voor regions - gelaagde optimalisatie zonder conflict.

### **3. Type- en Structuurdefinities**
```cpp
// Basis types
```

## **II. Host Orchestratie & Geheugenbeheer**

### **1. VRAM-beheer en Paginering**
- **Veilige Data Limiet (V_safe)**: Look-up tabel per GPU (RTX 2060: 3.5 GB, RTX 4070: 10.0 GB)
- **Implementatie**: `cudaMemGetInfo()` + GPU-naam lookup
- **Rationale**: Houdt 2.0-2.5 GB reserve voor overhead

### **2. Recursieve Workload Splitsing**
- **Principe**: Split langs langste as (V_x') op basis van point-count
- **Doel**: Herstel Morton-anisotropie (1:2 bitverhouding)
- **As-hernaming**: Swappen van `AxisChunk` structs bij elke splitsing voor uniforme X', Y', Z'

### **3. Workflow**
1. Bepaal V_safe via GPU lookup
2. Split wolk in pagina's binnen V_safe limiet
3. Recursief splits chunks tot gebalanceerde workload
4. Map chunks naar GPU met correcte as-mapping

## **IV. RDV Voter Kernel - `k_adaptive_rdv_voter.cu`**

### **1. Cache Structuur en Logica**
- **Hoofdcache**: K slots (bijv. 12-16) voor richtingen
- **Ringbuffer**: N=8 voor nieuwe radiaal detectie

### **2. `tryMatchAndNudgeMainCache` - Kernfunctionaliteit**
```cpp

    // Zoek beste match in cache
    // Switch tussen cos³² (vlak) en sin³² (buis)
    // Als match > drempel: nudging + return true
    // Anders: return false (geen stem, geen nudge)

```

### **3. Nudging Mechanisme**
- **Formule**: Running Average: `V_nieuw = (1-α)·V_oud + α·n_nieuw`
- **α**: `1 / (Count + Init)` voor statistisch zuivere middeling
- **Beveiliging**: Gewicht met `cos²ⁿ(θ)` als zelf-beveiligend filter
- **Hard cutoff**: 20° hoeklimiet voor workload reductie

### **4. Vormdetectie Logica**
| Vorm | Geometrie | Gewichtsfunctie | Actie |
|------|-----------|----------------|-------|
| **Vlak** | n_in ∥ V_as | `cos³²(θ)` | Direct nudgen parallelle richting |
| **Buis** | n_in ⊥ V_as | `sin³²(θ)` | Nudgen orthogonale as |
| **Geen match** | θ > 20° | - | Naar ringbuffer |

### **5. Gewichtsberekening Functies**
```cpp
__device__ float cos32_pow(float cos_val) {
    // 5 vermenigvuldigingen: x² → x⁴ → x⁸ → x¹⁶ → x³²

__device__ float sin32_pow(float angle_rad) {
    // sin(x) = cos(π/2 - x) identiteit
    return cos32_pow(cosf(1.57079632679f - angle_rad));
```

## **IV. RDV Voter Kernel - `k_adaptive_rdv_voter.cu`** (Gecorrigeerd)

### **4. Vormdetectie en Stemlogica**

De kernel onderscheidt dynamisch tussen **vlakken** en **buizen** en past de stemming dienovereenkomstig aan:

#### **A. Vlakdetectie en Stemming**
```cpp
// Pseudo-code voor vlak-burst detectie en stemming
__device__ void processIncomingNormal(float3 n_in) {
    // Controleer of dit deel uitmaakt van een vlak-burst
    if (isPlaneBurst(n_in, previous_normals)) {
        // VLAK MODUS: Stem op parallelle richting
        
        // 1. Zoek beste vlakrichting in cache (θ ≈ 0°)
        int best_slot = -1;
        float max_cos_weight = 0.0f;
        
        for (int i = 0; i < CACHE_SIZE; i++) {
            float cos_theta = fabsf(dot(n_in, cache.axes[i]));
            float weight = cos32_pow(cos_theta);
            
            if (weight > max_cos_weight && weight > MIN_VLAK_DRUMPEL) {
                max_cos_weight = weight;
                best_slot = i;
            }
        }
        
        // 2a. Als match gevonden: Nudge deze as
        if (best_slot >= 0) {
            // Running average nudging
            float alpha = 1.0f / (cache.counts[best_slot] + INIT_COUNT);
            cache.axes[best_slot] = normalize(
                (1.0f - alpha) * cache.axes[best_slot] + 
                alpha * n_in * max_cos_weight  // Gewogen door fit-kwaliteit
            );
            cache.counts[best_slot]++;
            return; // KLAAR - vlak is verwerkt
        }
        
        // 2b. Geen bestaande vlakrichting: creëer nieuwe
        if (cache.hasEmptySlot()) {
            cache.addNewAxis(n_in, INIT_COUNT);
            return;
        }
    }
    
    // GEEN VLAK → ga naar buis/radiaal logica
    processAsRadial(n_in);
}
```

#### **B. Buisdetectie en Stemming**
```cpp
__device__ void processAsRadial(float3 radiaal) {
    // BUIS MODUS: Stem op orthogonale richting (θ ≈ 90°)
    
    // 1. Zoek beste orthogonale as in cache
    int best_slot = -1;
    float max_sin_weight = 0.0f;
    
    for (int i = 0; i < CACHE_SIZE; i++) {
        float cos_theta = fabsf(dot(radiaal, cache.axes[i]));
        float angle = acosf(cos_theta);
        float weight = sin32_pow(angle);  // Beloning voor 90°
        
        if (weight > max_sin_weight && weight > MIN_BUIS_DRUMPEL) {
            max_sin_weight = weight;
            best_slot = i;
        }
    }
    
    // 2a. Match gevonden: Nudge orthogonale as
    if (best_slot >= 0) {
        // RADIAAL STEMT OP BUIS-AS
        float alpha = 1.0f / (cache.counts[best_slot] + INIT_COUNT);
        
        // Radiaal moet loodrecht staan op buis-as
        // Nudge de as richting de loodrechte van de radiaal
        float3 orthogonal_component = radiaal - dot(radiaal, cache.axes[best_slot]) * cache.axes[best_slot];
        if (length(orthogonal_component) > EPSILON) {
            orthogonal_component = normalize(orthogonal_component);
            cache.axes[best_slot] = normalize(
                (1.0f - alpha) * cache.axes[best_slot] + 
                alpha * orthogonal_component * max_sin_weight
            );
        }
        cache.counts[best_slot]++;
        cache.weights[best_slot] += max_sin_weight;
        return;
    }
    
    // 2b. Geen match: naar ringbuffer voor nieuwe hypothese
    inkomendeRadiaal(radiaal);
}
```

#### **C. Vlak-Burst Detectie Logica**
```cpp
__device__ bool isPlaneBurst(float3 n_in, float3* previous_normals, int& burst_counter) {
    // Check op opeenvolgende parallelle normals
    const float PLANE_THRESHOLD = 0.98f;  // cos(≈11°)
    
    for (int i = 0; i < BURST_WINDOW; i++) {
        if (dot(n_in, previous_normals[i]) > PLANE_THRESHOLD) {
            burst_counter++;
            if (burst_counter >= MIN_BURST_COUNT) {
                return true;  // VLAK-BURST GEDETECTEERD
            }
        }
    }
    
    burst_counter = max(0, burst_counter - 1);  // Decay
    return false;
}
```

### **5. Geometrische Relaties - Volledig Overzicht**

| Situatie | Inkomende Vector | Doel-Richting | Gewichtsfunctie | Stem-Actie |
|----------|------------------|---------------|-----------------|------------|
| **Vlak (Burst)** | Normal `n` | Parallel aan `n` | `cos³²(θ)` | `n` stemt op **zichzelf** (parallelle richting) |
| **Buis (Radiaal)** | Normal `n` | Loodrecht op `n` | `sin³²(θ)` | `n` stemt op **orthogonale as** |
| **Nieuw Vlak** | Normal `n` | - | `cos³²(θ)` | Creëert nieuwe cache-entry |
| **Nieuwe Buis** | Normal `n` | - | `sin³²(θ)` | Gaat naar ringbuffer voor hypothese |

### **6. Belangrijke Correctie op OTNDC**
De traditionele OTNDC fout is dat **alle normals op orthogonale richtingen stemmen**. Onze architectuur corrigeert dit:

- **VLAKKEN**: Normals stemmen op **parallelle richting** (`cos³²`)
- **BUISEN**: Normals (radialen) stemmen op **orthogonale richting** (`sin³²`)

Dit betekent dat de **Vlak-Burst detectie essentieel is** - zonder deze detectie zouden vlaknormals ten onrechte op buisrichtingen stemmen.

### **7. Stem-Doorstroming Diagram**
```
Inkomende Normal
    ↓
[Is PlaneBurst?] → JA → Stem op PARALLELE richting (cos³²)
    ↓ NEE
[Is Orthogonal Match?] → JA → Stem op ORTHOGONALE richting (sin³²)
    ↓ NEE
[Ringbuffer voor nieuwe hypothese]
    ↓
[Sweep bij volle buffer]
    ↓
[Genereer nieuwe buisas]
```

```cpp
// Kern van de stemming - integratie in tryMatchAndNudgeMainCache
__device__ bool tryMatchAndNudgeMainCache(float3 n_in, bool is_plane_burst) {
    if (is_plane_burst) {
        // VLAK STEM: zoek beste parallelle match
        return findAndNudgeBestMatch(n_in, COS_MODE);
    } else {
        // BUIS STEM: zoek beste orthogonale match
        return findAndNudgeBestMatch(n_in, SIN_MODE);
    }
}

enum MatchMode { COS_MODE, SIN_MODE };

__device__ bool findAndNudgeBestMatch(float3 n_in, MatchMode mode) {
    float best_weight = 0.0f;
    int best_idx = -1;
    
    for (int i = 0; i < CACHE_SIZE; i++) {
        float cos_theta = dot(n_in, cache.axes[i]);
        float weight;
        
        if (mode == COS_MODE) {
            weight = cos32_pow(fabsf(cos_theta));  // Parallel belonen
        } else { // SIN_MODE
            float angle = acosf(fabsf(cos_theta));
            weight = sin32_pow(angle);  // Orthogonaal belonen (90°)
        }
        
        if (weight > best_weight && weight > MIN_STEM_DRUMPEL) {
            best_weight = weight;
            best_idx = i;
        }
    }
    
    if (best_idx >= 0) {
        // NUDGING TOEPASSEN
        nudgeAxis(best_idx, n_in, best_weight, mode);
        return true;
    }
    
    return false;  // GEEN STEM UITGEVOERD
}
```

**Belangrijk**: De stemming gebeurt dus **selectief**:
- Vlakken → stemmen alleen op vlakrichtingen
- Buizen → stemmen alleen op buisrichtingen
- Geen match → geen stemming (gaat naar ringbuffer)

Dit voorkomt de OTNDC fout en zorgt voor snellere, nauwkeurigere consensusvorming.

## **Correcte Logica: Stemmen op het Duale Vlak**

### **1. Geometrische Relaties Herzien**

Voor een **kruisproduct** (potentiële buis-as) `C = A × B`:
- `C` = buis-as richting (loodrecht op vlak van A en B)
- **Duaal vlak** = vlak gespannen door A en B (of elke vector loodrecht op C)
- **Normaal van duaal vlak** = `C` zelf (of elke vector parallel aan C)

Een **radiaal** die bij een buis hoort:
- Moet **loodrecht** staan op de buis-as `C` (hoek ≈ 90°)
- Moet dus **parallel** zijn aan het duaal vlak
- En moet **loodrecht** staan op de normaal van het duaal vlak (die is `C`)

### **2. Correcte Implementatie**

```cpp
__device__ void inkomendeRadiaal(float3 nieuwe_radiaal) {
    // Buffer vol check
    bool buffer_vol = (ringCount == 8);
    
    if (!buffer_vol) {
        // Gewoon toevoegen
        Ring[posNext] = nieuwe_radiaal;
        ringCount++;
        posNext = (posNext + 1) & 7;
        return;
    }
    
    // ★★★ KRITIEK: Oude radiaal laat stemmen ★★★
    int pos_te_overschrijven = posNext;
    float3 oude_radiaal = Ring[pos_te_overschrijven];
    
    // STAP 1: Check of oude radiaal kan stemmen op BESTAANDE cache-assen
    // (Dit gebeurt in de normale stemming flow - niet hier)
    
    // STAP 2: Check of oude radiaal kan stemmen op KRUISPRODUCTEN
    // die al gegenereerd zijn uit andere radialen in de buffer
    
    // Doorloop alle mogelijke paren in de buffer
    float beste_gewicht = 0.0f;
    float3 beste_buis_as = {0,0,0};
    
    for (int i = 0; i < 8; i++) {
        if (i == pos_te_overschrijven) continue;  // Skip zichzelf
        
        for (int j = i+1; j < 8; j++) {
            if (j == pos_te_overschrijven) continue;
            
            float3 r1 = Ring[i];
            float3 r2 = Ring[j];
            
            // Genereer kruisproduct (potentiële buis-as)
            float3 kruis = normalize(cross(r1, r2));
            
            // ★★★ Check of OUDE RADIAAL op het DUAL VLAK kan stemmen ★★★
            // Oude radiaal moet ~loodrecht staan op kruis (de buis-as)
            // Dit betekent: hoek tussen oude_radiaal en kruis ≈ 90°
            
            float cos_hoek = fabsf(dot(oude_radiaal, kruis));
            
            // ★★★ CORRECTE CHECK: gebruik sin(θ) of cos(90°-θ) ★★★
            // We willen hoeken dicht bij 90° belonen
            // Dit is gelijk aan cos(θ) dicht bij 0 belonen
            
            if (cos_hoek < COS_75) {  // cos(75°) ≈ 0.2588, hoek ≥ 75°
                // Bereken het gewicht: hoe dichter bij 90°, hoe beter
                // sin²ⁿ(θ) = (1 - cos²(θ))ⁿ voor hoeken rond 90°
                
                float angle = acosf(cos_hoek);
                float gewicht = sin32_pow(angle);  // sin³²(θ)
                
                // ★★★ BELANGRIJK: Extra validatie ★★★
                // De twee radialen r1 en r2 moeten ook ~loodrecht op kruis staan
                float cos_r1 = fabsf(dot(r1, kruis));
                float cos_r2 = fabsf(dot(r2, kruis));
                
                if (cos_r1 < COS_75 && cos_r2 < COS_75) {
                    // Alledrie ~loodrecht op dezelfde as → sterke buis-hypothese
                    float totaal_gewicht = (gewicht + sin32_pow(acosf(cos_r1)) + 
                                           sin32_pow(acosf(cos_r2))) / 3.0f;
                    
                    if (totaal_gewicht > beste_gewicht) {
                        beste_gewicht = totaal_gewicht;
                        beste_buis_as = kruis;
                    }
                }
            }
        }
    }
    
    // STAP 3: Als geldige hypothese, injecteer in cache
    if (beste_gewicht > T_VALIDATIE) {
        injecteerInCache(beste_buis_as, beste_gewicht);
        
        // Buffer clearing
        ringCount = 0;
        posNext = 0;
        Ring[0] = nieuwe_radiaal;
        ringCount = 1;
        posNext = 1;
        return;
    }
    
    // STAP 4: Geen match - doe O(1) sweep met NIEUWE radiaal
    // ... bestaande sweep logica ...
    
    // Overschrijf tenslotte
    Ring[posNext] = nieuwe_radiaal;
    posNext = (posNext + 1) & 7;
}
```

### **3. Wiskundige Correctie**

Je hebt gelijk over de hoekberekening:

Voor een **radiaal** `R` en een **buis-as** `C`:
- Ideaal: `R ⊥ C` (hoek = 90°)
- Acceptabel: hoek tussen 75° en 105° (15° tolerantie)
- `cos(75°) ≈ 0.2588`, `cos(105°) ≈ -0.2588`

**Check**: `|dot(R, C)| < cos(75°) ≈ 0.2588`

Dit is equivalent aan:
- `sin(θ) > cos(15°) ≈ 0.9659` (voor θ ≈ 90°)
- Of: `|θ - 90°| < 15°`

### **4. Volledige Correctie in Gewichtsberekening**

```cpp
__device__ float berekenBuisGewicht(float3 radiaal, float3 buis_as) {
    float cos_theta = fabsf(dot(radiaal, buis_as));
    
    // ★★★ CORRECT: Hoek van 90° is ideaal ★★★
    // sin(θ) is maximaal bij θ = 90°
    // sin³²(θ) beloont hoeken dicht bij 90°
    
    float angle = acosf(cos_theta);
    return sin32_pow(angle);

// Of efficiënter zonder acos:
__device__ float berekenBuisGewichtEfficient(float3 radiaal, float3 buis_as) {
    float cos_theta = fabsf(dot(radiaal, buis_as));
    
    // sin²(θ) = 1 - cos²(θ)
    float sin2_theta = 1.0f - cos_theta * cos_theta;
    
    // sin³²(θ) = (sin²(θ))¹⁶
    float sin32 = sin2_theta * sin2_theta;  // sin⁴
    sin32 = sin32 * sin32;  // sin⁸
    sin32 = sin32 * sin32;  // sin¹⁶
    sin32 = sin32 * sin32;  // sin³²
    
    return sin32;
}
```

```cpp
                                       float& uit_gewicht) {

    uit_gewicht = sin32_pow(angle);
    
    return (uit_gewicht > MIN_GEWICHT);
}
```

1. **Oude radiaal R_oud** staat op punt overschreven te worden
2. **Eerst checken**: Kan R_oud stemmen op bestaande cache-assen? (normale flow)
3. **Dan checken**: Kan R_oud met andere radialen in buffer een buis vormen?

5. **Anders**: R_oud wordt overschreven zonder verder effect

__device__ void injecteerInCache(float3 nieuwe_as) {
    // 1. Bepaal injectie positie (laatste vrije of evict positie)
    int inject_idx;
    
    if (cache_count < CACHE_SIZE) {
        // Nog ruimte: voeg toe aan einde
        inject_idx = cache_count;
        cache_count++;
    } else {
        // Cache vol: overschrijf oudste (FIFO) of cyclisch
        inject_idx = cache_next_evict;
        cache_next_evict = (cache_next_evict + 1) % CACHE_SIZE;
    }
    
    // 2. Botweg overschrijven (zelfs als hoger gewicht)
    cache.axes[inject_idx] = nieuwe_as;
    cache.weights[inject_idx] = 1.0f;      // Startgewicht = 1
    cache.counts[inject_idx] = 1;          // Start count = 1
}

__device__ bool tryMatchAndNudgeMainCache(float3 n_in) {
    float best_weight = MIN_NUDGE_THRESHOLD;
    int best_idx = -1;
    
    // Simpele lineaire scan (geen sortering nodig)
    for (int i = 0; i < cache_count; i++) {
        float cos_theta = fabsf(dot(n_in, cache.axes[i]));
        
        // Kies max van cos³² (vlak) of sin³² (buis)
        float w_flat = cos32_pow(cos_theta);
        float w_tube = sin32_pow(acosf(cos_theta));
        float w_final = fmaxf(w_flat, w_tube);
        
        if (w_final > best_weight) {
            best_weight = w_final;
            best_idx = i;
        }
    }
    
    if (best_idx != -1) {
        // NUDGE met running average
        float alpha = 1.0f / (cache.counts[best_idx] + 1.0f);
        
        // Gewicht door fit-kwaliteit
        float3 gewogen_nieuwe = n_in * best_weight;
        
        cache.axes[best_idx] = normalize(
            (1.0f - alpha) * cache.axes[best_idx] + 
            alpha * gewogen_nieuwe
        );
        
        cache.weights[best_idx] += best_weight;
        cache.counts[best_idx]++;
        
        return true;  // Gestemd en genudged
    }
    
    return false;  // Geen match → naar ringbuffer
}

__device__ void inkomendeRadiaal(float3 nieuwe_radiaal) {
    // 1. Probeer eerst directe cross met ringbuffer
    if (ringCount >= 1) {  // Minstens 1 andere radiaal nodig
        float beste_hoek = 0.0f;
        int beste_idx = -1;
        
        // Zoek beste partner (dichtst bij 90°)
        for (int i = 0; i < ringCount; i++) {
            float cos_hoek = fabsf(dot(nieuwe_radiaal, Ring[i]));
            float hoek = acosf(min(1.0f, cos_hoek));
            
            if (hoek > 1.2217f) {  // > 70°
                float afstand_tot_90 = fabsf(hoek - 1.5708f);
                if (afstand_tot_90 < fabsf(beste_hoek - 1.5708f)) {
                    beste_hoek = hoek;
                    beste_idx = i;
                }
            }
        }
        
        if (beste_idx != -1) {
            // Maak cross en injecteer
            float3 cross_as = normalize(cross(nieuwe_radiaal, Ring[beste_idx]));
            injecteerInCache(cross_as);
            
            // Laat nieuwe radiaal direct stemmen op deze cross
            if (tryMatchAndNudgeMainCache(nieuwe_radiaal)) {
                return;  // KLAAR
            }
        }
    }
    
    // 2. Buffer nog niet vol? Voeg toe
    if (ringCount < 8) {
        Ring[posNext] = nieuwe_radiaal;
        ringCount++;
        posNext = (posNext + 1) & 7;
        return;
    }
    
    // 3. Buffer VOL: evict-radiaal krijgt laatste kans
    int evict_pos = posNext;  // FIFO: oudste
    float3 evict_radiaal = Ring[evict_pos];
    
    // Probeer cross met andere buffer elementen
    for (int i = 0; i < 8; i++) {
        if (i == evict_pos) continue;
        
        float cos_hoek = fabsf(dot(evict_radiaal, Ring[i]));
        if (cos_hoek < 0.342f) {  // > 70°
            float3 kruis = normalize(cross(evict_radiaal, Ring[i]));
            
            // Valideer orthogonaal
            float w1 = sin32_pow(acosf(fabsf(dot(evict_radiaal, kruis))));
            float w2 = sin32_pow(acosf(fabsf(dot(Ring[i], kruis))));
            
            if ((w1 + w2) * 0.5f > 0.3f) {  // T_VALIDATIE
                injecteerInCache(kruis);
                
                // Buffer reset
                ringCount = 0;
                posNext = 0;
                Ring[0] = nieuwe_radiaal;
                ringCount = 1;
                posNext = 1;
                return;
            }
        }
    }
    
    // 4. Geen succes: overschrijf
    Ring[posNext] = nieuwe_radiaal;
    posNext = (posNext + 1) & 7;
}
