__device__ bool tryMatchAndNudgeMainCache(const float3& n_in, RdvCache* cache) {
    float max_weight = MIN_NUDGE_THRESHOLD;  // Zachte cutoff (bijv. 0.1)
    int best_slot = -1;
    
    // Loop over K slots (bijv. 16)
    for (int i = 0; i < CACHE_SIZE_K; ++i) {
        float3 v_as = cache->axes[i];
        
        // Bereken cos(theta) (geabsolutiseerd voor symmetrie)
        float cos_theta = fabsf(dot(n_in, v_as));
        
        // Dynamische switch: Vlak (parallel) vs Buis (orthogonaal)
        float w_flat = cos32_pow(cos_theta);  // cos^32 voor vlakken (θ ≈ 0°)
        float w_tube = sin32_pow(acosf(cos_theta));  // sin^32 voor buizen (θ ≈ 90°)
        
        // Kies dominante gewicht
        float w_final = fmaxf(w_flat, w_tube);
        
        // Beste match?
        if (w_final > max_weight) {
            max_weight = w_final;
            best_slot = i;
        }
    }
    
    // Geen match? → Ringbuffer (return false)
    if (best_slot == -1) {
        return false;  // Geen stemmen/nudging
    }
    
    // Match gevonden → Nudge & stem
    nudgeAxis(cache, best_slot, n_in, max_weight);
    return true;  // Gestemd/Genudged
}

#### I. Type- en Structuurdefinities

Deze kernel produceert zuivere normals en filtert ruis. Het is de start van de pipeline en richt zich op efficiënte, lokale filtering.

#### III. Voter-Kernel: `k_adaptive_rdv_voter.cu` (De Verfijning)
Deze kernel verwerkt de normals uit de producer met dynamische stemming en nudging. Het is de intelligente core voor as-verfijning.

- **Ringbuffer Structuur**: `float3 Ring[8]` met cyclische pointer `posNext = (posNext + 1) & 7`. Initieel gevuld met nul-vectoren.

- **Evictie**: Laagst scorende as uit cache (bubble swap om cache ongesorteerd te houden).

#### V. Ringbuffer en Buisas Generatie
- **Ringbuffer Structuur**: `float3 Ring[8]` met cyclische `posNext = (posNext + 1) & 7`. Initieel nul-vectoren.
- **`inkomendeRadiaal(float3 radiaal)`**: Gatekeeper voor ringbuffer. Aangeroepen bij `tryMatchAndNudgeMainCache` false.
  - **Vulling**: Als `ringCount < 8`: Voeg toe, ringCount++, posNext update. Return.
  - **Sweep bij Volle Buffer**: Als `ringCount == 8`: 
    - Oude radiaal (`Ring[pos_te_overschrijven]`) krijgt laatste kans: Test kruisproduct met nieuwe radiaal of andere buffer-elementen voor ≥70° hoek. Bij succes: Genereer kruisproduct, injecteer in cache, clear buffer, voeg nieuwe toe.
    - Geen succes: Voer O(1) sweep uit met nieuwe radiaal als anker (test vaste offsets i vs. i+3).
  - **Overschrijven**: Altijd aan einde: `Ring[posNext] = nieuwe_radiaal`, posNext update.
  - **Buffer Reset**: Crude clearing alleen bij succesvolle hypothese (ringCount = 1, posNext = 1).
- **Sweep Algoritme**: O(1) - vaste cyclische afstanden testen voor ≥70° hoek. Valideren met `T_validatie`. Injecteer nieuwe as met laag startgewicht (0 of 1).
- **Evictie**: Bubble swap + evict laagste weight.

- **Seeding Strategie**: 3 assen van current frame (X_cur, Y_cur, Z_cur) als seeds in RDV-cache met lage start-count.
- **Vlak-Burst Detectie**: Opeenvolgende parallelle normals (`dot > 0.98` in BURST_WINDOW). Stem direct op eigen richting met `cos^{32}`.
- **Stopcriterium**: Top 3 orthogonale richtingen >90% van stemmen (adaptief).
- **Globale Reductie**: Host MapReduce: Gewogen gemiddelde van lokaal genudgete assen uit chunks.
- **Early-Out**: Parallelle chunk verwerking + snelle consensus.
